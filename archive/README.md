# Archive

`crystal/` is Slang for Crystal as it was at its last release, 2.0.3
(toddsundsted/slang, a fork of jeromegn/slang): its source, specs, README,
shard.yml and CI configuration, unchanged. It is kept for reference and for
its history, and is no longer maintained; the iyi port at the root of this
repository follows it.

To keep using the Crystal version, depend on
[toddsundsted/slang](https://github.com/toddsundsted/slang) at v2.0.3.
